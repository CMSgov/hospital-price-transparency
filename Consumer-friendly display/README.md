# Consumer-friendly Display

This folder contains the following materials to help hospitals meet the consumer-friendly display requirements under 45 CFR § 180.60 of the Hospital Price Transparency regulations:

- [Shoppable Services Voluntary Sample File Data Dictionary](./SHOPPABLE_SERVICES_VOLUNTARY_SAMPLE_FILE_DATA_DICTIONARY.pdf)
- [Shoppable Services Voluntary Sample File](./SS_Sample_Format.xlsx)
- [Example Sample File](./SS_Sample_Format_Example_File.xlsx)
- [Shoppable Services Voluntary Sample File Consumer Guide](./SHOPPABLE_SERVICES_VOLUNTARY_SAMPLE_FILE_CONSUMER_GUIDE.pdf)

Use of the shoppable services voluntary sample file is optional. Hospitals that use it must include all data elements required by 45 CFR § 180.60(b).
